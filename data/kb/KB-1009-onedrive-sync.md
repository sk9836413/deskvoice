## Symptoms
Files show a red cross or "sync pending", or changes do not appear on other devices.

## Steps
1. Click the OneDrive cloud icon in the taskbar and read the error message.
2. Make sure you are signed in and not out of storage.
3. Pause syncing, then resume it from the OneDrive menu.
4. Check the file name has no unsupported characters and the path is not too long.
5. Restart OneDrive by quitting it from the menu and opening it again.

## Raise a ticket if
OneDrive keeps showing a sync error for many files.
